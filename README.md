CivicWatch NG is a simple web app for reporting civic issues in Nigeria.

Key details

Purpose: Citizens can report everyday community problems so authorities can see them in real time. The tagline is “Help your community. Authorities see new reports in real-time.”

Focus: Nigeria-specific (the “NG” stands for Nigeria). Categories use local terms like Danfo (yellow buses) and BRT.

Tech: Built with Next.js and hosted on Vercel (evident from the URL and page assets).

Issue categories

Users pick from six main types:

CategoryExamplesTraffic violationReckless drivers, one-wayPublic transportDanfo, BRT, bus stopsIllegal dumpingRefuse, debris, blocked drainsRoad damagePotholes, broken kerbsPollutionSmoke, oil spill, noiseSafety / CrimeSuspicious activity, hazards

How it looks

The homepage is clean and minimal:

Logo and title “CivicWatch NG”

Heading “Report an issue”

A card grid of the six categories with icons

Soft light-green background

Selecting a category would normally open a reporting form (description, location, photo, etc.), though the public homepage itself is mainly the category selector.
